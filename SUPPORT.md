# Support

Not sure where to ask? Pick the line that fits.

| I want to... | Go to |
|---|---|
| Ask a question, share an idea or show what I built | [GitHub Discussions](https://github.com/Opencomplai/opencomplai/discussions) |
| Report a bug | [Bug report form](https://github.com/Opencomplai/opencomplai/issues/new?template=bug-report.yml) |
| Propose a feature | [Feature request form](https://github.com/Opencomplai/opencomplai/issues/new?template=feature-request.yml) |
| Report a security vulnerability | [Security policy](SECURITY.md). Please do **not** open a public issue |
| Chat quickly with other users | [Developer Discord](https://discord.gg/egjX5JgQJ). Anything worth keeping belongs in Discussions, where it stays searchable |
| Raise a private concern | [open@opencomplai.com](mailto:open@opencomplai.com) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

## How fast to expect an answer

We aim to give every new issue, pull request and Discussion a **first reply within 48 hours on working days**. That reply may be a question, a pointer, or a plain "not now", but it will be a reply. If something has been quiet for a week, a short bump is welcome.

This is a small team. During public holidays the target can stretch, and we say so in Discussions when it does.

## Before you ask

- Search the [existing issues](https://github.com/Opencomplai/opencomplai/issues) and [Discussions](https://github.com/Opencomplai/opencomplai/discussions) first.
- For a bug, include the output of `opencomplai --version`, your operating system and the smallest example that shows it.

The full list of channels, with the issue forms and the security reporting rules, is on the [Support and Community](docs/src/community/support.md) page of the docs.
